# 練習タイマー beta

`index.html` を直接開いて使います。起動時はタイマー画面です。最初は手順が空なので、タイマー画面の「設定」→「＋追加」で作業または休憩の種類と時間を1行ずつ入力し、保存してください。行は矢印で並べ替えられます。最後に設定した作業時間と休憩時間を交互に繰り返します。

タスク画面では、タイトルだけで素早く追加できます。追加・編集のポップアップでは「やりたいこと」「最初の一手」「加算先の大分類・小分類」を設定します。小分類を選ばなければ大分類へ直接加算し、大分類も選ばなければ未分類になります。未完了タスクは「完了」で完了済みへ退避でき、「戻す」で復帰できます。過去の計測記録は残ります。

タイマー画面では開始前にも開始後にも「タスクを選ぶ」から未完了タスクを1つ選べます。開始前なら選び直せます。やりたいことを入力してEnterまたは「＋追加」で素早く追加でき、「詳細を入力して追加」から最初の一手や加算先も設定できます。計測中でタスクが未選択なら、追加したタスクをその回に選びます。開始後に選ぶ場合は、選ぶ前の作業時間も含めて加算され、別のタスクへ移るときは一度タイマーを終了します。選ばず終了した時間は「積み上げ」画面で後からタスクへ割り当てられます。育成項目は0件から親項目と内訳を追加でき、初版は分数の一覧です。最近の記録には任意の振り返りメモも残せます。

「設定」画面から、画像を含まないJSONを保存・読み込みできます。読み込みは現在のデータを置き換え、計測中は実行できません。通知の確認には、ブラウザが通知を許可できる環境が必要です。

`beta` 表示中は制作中です。設定や計測データを将来の版へ引き継ぐこと、旧データとの互換性は保証しません。

設定と累計作業時間はブラウザのローカルストレージに保存されます。作業途中でページを閉じた場合、再度開くと一時停止状態から再開できます。アプリを完全に終了した状態やPCのスリープ中には、音・通知は保証されません。
