# 練習タイマー

## 公開先

- 正式公開: https://ichilolule.github.io/practice-timer/
- 旧Sitesテスト環境: https://practice-timer-beta-20261110.annualvanilla2.chatgpt.site/ — 2026-11-13に非公開化し、所有者のみ閲覧可能。現在の公開先は上記GitHub Pagesです。

配色は `styles.css` 冒頭の `:root` に集約しています。`--color-surface` はクリーム色の背景、`--color-sidebar` はタスク欄のブルー、`--color-text` は文字、`--color-primary` は主ボタンと時計、`--color-accent` は円とグラフ、`--color-selection` はナビの選択色です。休憩の数字色は `--color-rest`、書体は `--font-ui` で変更できます。境界線・入力欄・ダイアログ・バックアップの案内も共通変数を使います。

文字はウィンドウ全体の倍率で縮めず、標準設定では本文・タスク名16px、補助情報14px前後、グラフ目盛り12pxを保ちます。ブラウザの文字サイズ・ズーム設定も反映します。アプリの最大幅は1000px相当で、タイマー円の表示枠は最大384px、見出しは最大30px、開始・一時停止ボタンは64〜80px、スキップ・停止は48pxの操作範囲と32pxのアイコン枠です。大きな窓では上限から拡大せず余白を増やします。調整用の寸法は `styles.css` 冒頭の変数にまとめています。幅401px以上ではTimerの左右配置、Reviewの合計とグラフ、Themes・Settingsの2列を保ち、小窓では余白やグラフの高さを詰めます。幅400px以下ではタイマーのタスク欄を下へ移し、Reviewの合計とグラフ、テーマカード、設定を縦1列に並べます。幅719px以下ではナビの文字を隠してアイコン表示にし、44px以上の操作範囲と読み上げ・ツールチップの操作名を残します。

UIは直感的でシンプルな操作を優先します。繰り返し使う中で配置や記号に慣れることを前提に、画面内の説明や冗長な操作を減らし、詳しい使い方はこのREADMEにまとめます。保存失敗など、対処が必要な情報は画面内に表示します。

`index.html` を直接開いて使います。起動時はタイマー画面です。下部の「Timer・Tasks・Review・Themes・Settings」で画面を切り替えます。画面内の操作・案内・エラーは英語で表示します。タスク名・テーマ名・メモなど、自分で入力した内容はそのまま保持します。最初は手順が空なので、「Settings」→「+ Add」で作業と休憩の時間を設定してください。追加時は直前と交互になる種類と、その種類の直近の時間（未設定ならWork 25分・Break 5分）を入れます。Routineはつまみ・種類・分数・削除を横1行にまとめ、つまみのドラッグで並べ替えられます。つまみにフォーカスして上下キーでも移動でき、Escapeやドラッグの中断で取り消せます。追加・削除・並べ替え・種類・時間の変更は自動保存します。入力途中の空欄や範囲外の値は適用せず、最後の有効な内容を保ちます。WorkとBreakが両方揃うまでは開始できません。401〜479pxでは設定の2列を保つため、種類と分数を上下に並べます。最後に設定した作業時間と休憩時間を交互に繰り返します。設定の編集中に別のタブへ移動しても入力を保持します。計測中の変更は次の計測から反映し、進行中の時間や工程は変えません。

タスク画面では、タイトルだけで素早く追加できます。新しいタスクは一覧の先頭へ追加します。画面下の入力欄は「Add task」と表示し、追加バーはスクロール中も下部ナビゲーションの上に残ります。完了済みタスクの末尾や取り消し通知が追加バーに重ならないよう、入力欄の折り返しに合わせて余白を調整します。未完了の見出しと件数は省いています。入力欄が空の状態（空白だけの場合も含む）で「+ Add」を押すと詳細入力が開き、「タイトル」「メモ」「テーマ」「サブテーマ」を設定できます。タイトルを入力済みなら「+ Add」ですぐに追加します。テーマは練習の分野や題材、サブテーマはその中の項目です（例：テーマ「人体」→サブテーマ「手」）。サブテーマを選ばなければテーマへ直接加算し、「サブテーマなし」と表示します。テーマ自体を選ばなければ「未設定」になります。一覧はチェックとタイトルを中心に表示し、タイトルを押すと直接「Edit task」を開きます。展開三角や「Use this task」は置かず、計測するタスクの選択はタイマー画面で行います。編集画面には「Save changes」「Cancel」「Delete」を横に並べ、Deleteは確認後にタスクだけを削除して過去の記録を残します。計測中の選択タスクは削除できません。チェックで完了済みへ移し、右下に約5秒表示する「Undo completion」ボタンまたは完了済みのチェック解除で復帰できます。連続して完了にした場合は最後の1件を取り消せます。完了・取り消しではスクロール位置を保ちます（一覧が短くなって画面の下端に達した場合は、表示可能な位置まで調整されます）。過去の計測記録は残ります。

タイマーは作業を鉛筆、休憩をカップで表示します。円の青い部分は現在の工程の残り時間を表し、12時の位置から時計回りに減ります。作業中の数字はブラウン、休憩中はブルーです。円の下の棒グラフアイコンはLogged（この回の作業時間）で、休憩と一時停止を含めず、終了時に記録へ保存して表示を0に戻します。一時停止中は小さな一時停止マークを添えます。主ボタンは再生マーク（開始・再開）と一時停止マークが同じ位置で切り替わり、左のスキップマークで次の工程へ進み、右の四角で終了して記録します。マウスを重ねると説明を確認でき、読み上げ用の操作名も付いています。手順がなければ主ボタンの歯車から設定へ進めます。開始前の時計には最初の設定時間を表示します。タイマーの終了とタスクの完了は別の操作です。

タイマー画面では幅401px以上で左1/3に未完了タスク、右2/3にタイマーを並べます。幅400px以下ではタイマーの下にタスク一覧と追加欄を置きます。「Practice tasks」の見出しと丸い選択マークは省き、タスクのタイトルを広く表示します。選択状態は背景色と文字の太さで示します。一覧に入りきらないタスクはスクロールし、長いタイトルは「…」で省略します。入力欄と「＋」から追加すると、そのタスクを選択します。追加したタスクは一覧の先頭に置きます。

タスクを選択して計測を始めると一覧を隠してタイマーを画面中央へ置きます。一時停止中も中央のままにし、終了すると左右配置へ戻します。左側のインライン編集欄はありません。上部のタスクタイトルを押すと編集ポップアップを開き、タイトル・メモ・テーマ・サブテーマを保存できます。変更はこの回の記録にも反映します。タイトルにマウスを重ねても下線は表示しません。未選択で計測を始めた場合はタイマー画面の一覧を残して後から選べるようにし、選択した時点で一覧を隠して中央表示にします。タイマー終了時の「Logged …」という文字行は省き、棒グラフアイコン横の作業時間は残します。

未完了タスクは、行の右端のつまみをドラッグして並べ替えられます。マウスとタッチに対応し、つまみにフォーカスして上下キーでも移動できます。タイマー画面では一覧の上下端で自動スクロールします。順序はタスク画面とタイマー画面で共通で、再読み込みやJSONバックアップにも引き継ぎます。完了済みは従来どおり完了日時の新しい順です。

通常の開始・再開・工程移行の説明は表示せず、アイコンと時間で状態を示します。保存・音・通知の失敗や長時間の中断は表示します。PCでは列の並びを保ち、タイマー円はタスク名・メモ・操作部を除いた残りの高さに収めます。計測前後で円の最大寸法は変えません。極端に小さな窓や長い内容で高さが足りないときはスクロールします。タイトルは設定画面にまとめています。タスク・振り返り・テーマ画面は、下部ナビゲーションと重複する最上部の見出しを省いています。

設定の「通知音」で、作業・休憩に共通の音量（0〜100%、0は消音）と音の高さ（標準から上下12半音＝1オクターブ）を調整できます。新しい100%は前版の500%相当で、1目盛りが前版の5%分です。前版の300%は60%、従来の標準100%は20%と表示し、保存済みの音の大きさはそのまま引き継ぎます。音の設定は変更時に自動保存され、次に鳴る音から反映します。「作業」「休憩」の再生ボタンで試聴できます。作業音は約0.48秒、休憩音は3音を約1.3倍速で鳴らす約0.58秒です。設定はJSONバックアップにも含め、音の設定がない旧バックアップは従来と同じ大きさ（新表示20%）で読み込みます。

ReviewではDay・Week・Month・Year・Allをつながった期間バーで切り替えます。All以外は前後の期間を見られます。幅401px以上では左に合計、右にグラフを置き、400px以下では合計の下にグラフを置きます。日付切り替えの文字は16px、前後ボタンの操作範囲は44pxを保ちながら上下の余白を詰めています。小窓ではグラフの高さと余白を減らし、Monthの2桁の日付が横にはみ出さないようグラフ左右の余白は保ちます。期間バーの文字は15px、操作範囲の高さは44px以上を保ちます。選択期間の合計を大きく、その下に全期間の累計を小さく表示します。作業時間の表示はテーマ・グラフ・記録保存時も含めてすべて `0h 25m`、`2h 05m`、`125h 30m` の形式です。秒は切り捨てて表示し、1分未満は`0h 00m`になりますが、記録自体の秒以下の精度は保持します。各項目と合計はそれぞれ集計してから切り捨てるため、表示上の足し算が一致しない場合があります。タイマーの残り時間には秒を表示します。

設定の「振り返り」→「1日の区切り」で日付を切り替える時刻を設定できます。初期値は朝5:00で、たとえば11月12日は11月12日5:00から翌13日5:00の直前までです。週は月曜始まりで月曜5:00〜翌月曜5:00、月・年もそれぞれ初日の設定時刻で区切ります。変更は自動保存し、過去の記録も新しい区切りで再集計します。記録の日時や総作業時間は変更しません。設定はJSONにも保存し、この設定を含まない従来のデータは5:00として読み込みます。

Day・Week・Month・Year・Allは、同じ縦棒グラフで作業時間を表示します。Allは最初の記録から最後の記録まで年別に比較し、空の年も表示します。年の棒からYear、月の棒からMonth、日の棒からDayへ移れます。年の境界にも「Day starts」の設定を使い、年をまたぐ区間を重複させません。日には区切りの時刻から1時間ずつ24本（5:00設定なら5時台〜翌4時台）、週・月には1日ずつ、年には1か月ずつの合計を表示します。時刻・日付・月の横軸と、作業時間の縦軸を共通の配置にし、混み合う日・月の横軸ラベルは間引きます。棒にマウスを重ねると各区間の時間を確認できます。週・月の棒を押すとその日、年の棒を押すとその月に移ります。日の縦軸上限は通常1時間で、週・月・年は作業量に合わせて変わります。端末のローカル時刻で集計し、夏時間の切替日などは実際の1日の長さに合わせて時間帯の本数が変わる場合があります。

ThemesもDay・Week・Month・Year・Allの期間バーを使い、初期表示はAllです。幅401px以上は2列、400px以下は1列のカードでテーマを表示します。テーマ名と時間はタスク名と同じ16pxの太字にそろえ、カードの上下の余白を詰めています。すべてのテーマとUnassignedを0時間でも表示し、共通の時間目盛りの横棒と数値で比較できます。時間は他の画面と共通の `100h 00m`、`2h 30m` の形式です。テーマの追加欄は従来どおり下部ナビゲーションの上に固定しています。

テーマカードを押すと詳細ポップアップを開きます。サブテーマの追加と比較、名前横の鉛筆からの名前変更・削除はこの中で行います。サブテーマの目盛りはそのテーマ内で共通とし、最長時間に薄い縦の目安線を置きます。0時間のサブテーマも表示し、全項目が0時間の場合は目安線を省きます。「No subtheme」は目安の計算に含めず別掲します。サブテーマの時間はテーマの合計に含まれます。テーマやサブテーマを削除してもタスク・記録・時間は残し、該当する割り当てを未設定に戻します。Unassignedカードのポップアップでは、テーマがない記録の時間をタスク名ごとにまとめます。

Dayの「Sessions」は時刻・鉛筆アイコン・タスク名・作業時間を1行に並べます。鉛筆は時刻とタスク名の間に配置し、テーマは表示しません。縮小時もこの並びを保ちます。長いタイトルは「…」で省略し、マウスを重ねると全文を確認できます。同じ集計日内の年月日は省き、集計日の外にまたがる区間では外側の日付を添えます。「この日」が付いた作業時間は、区間全体のうち選択した集計日内の時間です。行の鉛筆アイコンから日時、タスク、テーマ・サブテーマを直し、1件だけまたは同じタイマー起動分をまとめて削除できます。休憩と一時停止中は作業時間に入りません。

旧形式の記録には開始時刻がないため、「開始時刻なし」と表示し、終了時刻が属する集計日に合計します。時間帯を特定できないため日の24時間グラフには含めず、グラフの下に別掲します。日の合計・テーマタブの集計・週月年のグラフには含まれます。必要ならその記録の日時と作業時間を修正できます。振り返りメモはアプリには保存しません。

Settingsは幅401px以上で左にRoutine・Day starts、右にNotifications・Sound・Backupの2列構成です。400px以下ではRoutineからBackupまで1列に並べます。音量・高さの下にWork／Breakの試聴ボタンを置き、小窓では縦に並べて操作範囲を保ちます。NotificationsのOn／Off／Blocked／Unavailableは実際のブラウザ許可を示し、画面を開いたときやウィンドウに戻ったときに更新します。OSの通知抑制や集中モードの状態を示すものではありません。

Settingsから、画像を含まないJSONを保存・読み込みできます。読み込みは現在のデータを置き換え、計測中は実行できません。通知の確認には、ブラウザが通知を許可できる環境が必要です。

Backupの「Add destination」で、`practice-timer.json` の保存先を設定できます。iCloud Driveなど、端末から選べる場所へ名前を付けて複数登録できます。登録すると現在のタスク・時間・テーマ・各設定をすぐに書き出し、その後は変更が止まって2分後、計測中など変更が続く場合は5分ごとに自動保存します。保存先はこのブラウザに記憶し、再起動時にも引き継ぎます。保存先の登録自体はJSONには含めません。ファイル名は各保存先とも `practice-timer.json` で固定です。

保存先ごとに更新待ち・最終保存時刻・アクセス再許可・保存エラーを表示します。「Save now」で全保存先へ待たずに書き出せます。保存先がない場合や直接保存に非対応のブラウザでは、同じボタンからJSONをダウンロードします。別のダウンロードボタンは置いていません。「Import」でJSONを読み込みます。自動保存は常時オンで、旧版でオフにしていた設定もオンへ移行します。保存先の「•••」メニューには個別のSave／Change／Removeと、保存日時やエラーの詳細があります。Changeでファイルを選び直し、Removeで登録を外せます。解除してもファイルは削除しません。アクセス権が切れた場合は「保存」を押して再許可してください。別の操作でファイルが更新された場合は、その保存先への自動保存を止めます。ファイルの内容を確認し、「保存」から上書きするか、必要なJSONを読み込んで復元してください。JSONの読み込みが自動で行われることはありません。

自動保存はアプリを開いている間に動作します。計測途中の作業時間も含み、JSONを読み込んだときは一時停止状態で復元します。閉じる直前の変更までJSONへ残したい場合は「Save now」を押し、保存済みになったことを確認してください。ブラウザ内への保存は従来どおり継続します。ファイルへの保存済み表示は端末上での書き込みを表し、クラウドへの同期完了はFinderや保存先のサービスで確認してください。

自動保存はファイルへの直接保存に対応するブラウザ（Chrome・Edgeなど）で利用できます。非対応の場合も「Save now」によるダウンロードと「Import」は使えます。保存先を記憶できない場合は画面に表示し、次回は再設定が必要になる場合があります。ブラウザの保存データを読めないときは、空の内容でバックアップを上書きしないよう、保存先への書き出しを停止します。

設定と累計作業時間はブラウザのローカルストレージに保存されます。作業途中でページを閉じた場合、再度開くと一時停止状態から再開できます。アプリを完全に終了した状態やPCのスリープ中には、音・通知は保証されません。
