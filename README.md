# 練習タイマー beta

UIは直感的でシンプルな操作を優先します。繰り返し使う中で配置や記号に慣れることを前提に、画面内の説明や冗長な操作を減らし、詳しい使い方はこのREADMEにまとめます。保存失敗など、対処が必要な情報は画面内に表示します。

`index.html` を直接開いて使います。起動時はタイマー画面です。下部の「タイマー・タスク・積み上げ・テーマ・設定」で画面を切り替えます。最初は手順が空なので、「設定」→「＋追加」で作業または休憩の種類と時間を1行ずつ入力し、保存してください。行は矢印で並べ替えられます。最後に設定した作業時間と休憩時間を交互に繰り返します。設定の編集中に別のタブへ移動しても、入力は保存・キャンセルまで保持します。

タスク画面では、タイトルだけで素早く追加できます。「詳細をつける」から入力中のタイトルを引き継いで、「最初の一手」「テーマ」「サブテーマ」も設定できます。テーマは練習の分野や題材、サブテーマはその中の項目です（例：テーマ「人体」→サブテーマ「手」）。サブテーマを選ばなければテーマへ直接加算し、「サブテーマなし」と表示します。テーマ自体を選ばなければ「未設定」になります。一覧はチェックとタイトルを中心に表示し、タイトルを押すと詳細・タスク選択・編集が開きます。削除は詳細内の「その他の操作」にあります。チェックで完了済みへ移し、直後の「完了を取り消す」または完了済みのチェック解除で復帰できます。過去の計測記録は残ります。

タイマーは作業を鉛筆、休憩をカップで表示します。一時停止中は小さな一時停止マークを添えます。主ボタンは再生マーク（開始・再開）と一時停止マークが同じ位置で切り替わり、左のスキップマークで次の工程へ進み、右の四角で終了して記録します。マウスを重ねると説明を確認でき、読み上げ用の操作名も付いています。手順がなければ主ボタンの歯車から設定へ進めます。開始前の時計には最初の設定時間を表示します。タイマーの終了とタスクの完了は別の操作です。

タイマー画面には未完了タスクの一覧を常時表示し、タイトルを押してこの回のタスクを選べます。選択中のタスクは色で示し、開始前なら選び直せます。幅720px以上では左にタスク一覧、右にタイマーを並べ、一覧に入りきらないタスクだけスクロールします。720px未満ではタイマー→タスクの順に縦に並べます。「＋」を開き、Enterまたは「＋追加」で素早く追加でき、「詳細をつける」から最初の一手やテーマ・サブテーマも設定できます。計測中でタスクが未選択なら、追加したタスクをその回に選びます。開始後に選ぶ場合は、選ぶ前の作業時間も含めて加算され、別のタスクへ移るときは一度タイマーを終了します。計測中も一覧と追加欄を表示し、タスクが決まった後は一覧の選択を無効にします。一時停止中も選び直しは終了後に行います。

通常の開始・再開・工程移行の説明は表示せず、アイコンと時間で状態を示します。保存・音・通知の失敗や長時間の中断は表示します。低いウィンドウでは時計と余白を縮め、縦横比に関係なく横幅を基準に配置を切り替えます。タイトルは設定画面にまとめています。タスク・積み上げ・テーマ画面は、下部ナビゲーションと重複する最上部の見出しを省いています。

設定の「通知音」で、作業・休憩に共通の音量（0〜100%、0は消音）と音の高さ（標準から上下12半音＝1オクターブ）を調整できます。新しい100%は前版の500%相当で、1目盛りが前版の5%分です。前版の300%は60%、従来の標準100%は20%と表示し、保存済みの音の大きさはそのまま引き継ぎます。音の設定は変更時に自動保存され、次に鳴る音から反映します。「作業」「休憩」の再生ボタンで試聴できます。作業音は約0.48秒、休憩音は3音を約1.3倍速で鳴らす約0.58秒です。設定はJSONバックアップにも含め、音の設定がない旧バックアップは従来と同じ大きさ（新表示20%）で読み込みます。

積み上げ画面では日・週・月・年を切り替え、前後の期間を見られます。選択期間の合計を大きく、その下に全期間の累計を小さく表示します。作業時間の表示はテーマ・グラフ・記録保存時も含めてすべて `0h 25m`、`2h 05m`、`125h 30m` の形式です。秒は切り捨てて表示し、1分未満は`0h 00m`になりますが、記録自体の秒以下の精度は保持します。各項目と合計はそれぞれ集計してから切り捨てるため、表示上の足し算が一致しない場合があります。タイマーの残り時間には秒を表示します。

設定の「積み上げ」→「1日の区切り」で日付を切り替える時刻を設定できます。初期値は朝5:00で、たとえば11月12日は11月12日5:00から翌13日5:00の直前までです。週は月曜始まりで月曜5:00〜翌月曜5:00、月・年もそれぞれ初日の設定時刻で区切ります。変更は自動保存し、過去の記録も新しい区切りで再集計します。記録の日時や総作業時間は変更しません。設定はJSONにも保存し、この設定を含まない従来のデータは5:00として読み込みます。

日・週・月・年は、同じ縦棒グラフで作業時間を表示します。日には区切りの時刻から1時間ずつ24本（5:00設定なら5時台〜翌4時台）、週・月には1日ずつ、年には1か月ずつの合計を表示します。時刻・日付・月の横軸と、作業時間の縦軸を共通の配置にし、混み合う日・月の横軸ラベルは間引きます。棒にマウスを重ねると各区間の時間を確認できます。週・月の棒を押すとその日、年の棒を押すとその月に移ります。日の縦軸上限は通常1時間で、週・月・年は作業量に合わせて変わります。端末のローカル時刻で集計し、夏時間の切替日などは実際の1日の長さに合わせて時間帯の本数が変わる場合があります。

テーマ別の比較と追加・編集は独立した「テーマ」タブにまとめています。初期表示は全期間で、日・週・月・年にも切り替えられます。テーマの一覧には0時間の項目も表示し、共通の時間目盛りの横棒と、右端の数値で比較できます。時間はほかの画面と共通の `100h 00m`、`2h 30m` の形式です。

テーマを開くと、すべてのサブテーマを横棒で比較できます。目盛りはそのテーマ内で共通とし、最長時間に薄い縦の目安線を置きます。「目安」は登録済みサブテーマの中で最も長い作業時間で、0時間だけの場合は線を表示しません。「サブテーマなし」の時間は目安の計算に含めず別掲します。サブテーマの時間はテーマの合計に含まれます。テーマ間とサブテーマ内では比較の範囲が異なるため、それぞれに時間目盛りを表示します。テーマの追加欄は一覧の最下部にカードと同じ大きさで常時表示します。「テーマを追加」に名前を入力し、Enterまたは「追加」で登録できます。サブテーマの追加はテーマを開いた先、名前変更・削除はその中の「編集」にあります。

日の画面ではタスクと作業時間を主に、開始・終了時刻とテーマを補助情報として表示します。同じ集計日内の年月日は省き、集計日の外にまたがる区間では外側の日付を添えます。「この日」が付いた作業時間は、区間全体のうち選択した集計日内の時間です。行の「修正・削除」から日時、タスク、テーマ・サブテーマを直し、1件だけまたは同じタイマー起動分をまとめて削除できます。休憩と一時停止中は作業時間に入りません。テーマが未設定の記録は日の画面で「未設定のみ」に絞り込めます。

旧形式の記録には開始時刻がないため、「開始時刻なし」と表示し、終了時刻が属する集計日に合計します。時間帯を特定できないため日の24時間グラフには含めず、グラフの下に別掲します。日の合計・テーマタブの集計・週月年のグラフには含まれます。必要ならその記録の日時と作業時間を修正できます。振り返りメモはアプリには保存しません。

「設定」画面から、画像を含まないJSONを保存・読み込みできます。読み込みは現在のデータを置き換え、計測中は実行できません。通知の確認には、ブラウザが通知を許可できる環境が必要です。

`beta` 表示中は制作中です。設定や計測データを将来の版へ引き継ぐこと、旧データとの互換性は保証しません。

設定と累計作業時間はブラウザのローカルストレージに保存されます。作業途中でページを閉じた場合、再度開くと一時停止状態から再開できます。アプリを完全に終了した状態やPCのスリープ中には、音・通知は保証されません。
